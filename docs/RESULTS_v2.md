# ChronoArch v2 实验结果

## 方法、划分与指标

沿用第一轮的图像、教堂 ID、WC6/WC14/WC4 划分及 RQ3a/RQ3b 五折教堂分组。WC6、WC14 主指标为平衡准确率；Gothic、Romanesque 为 AUROC；断代为 MAE（年，越低越好）。区间为 1,000 次教堂级 bootstrap 的 95% CI。超参数与早停只看验证集；正常完成的最终配置测试预测只保存一次。一次中断的断代基线读出未形成结果，其 .incomplete 标记保留在 results_v2/，恢复经过见 RUN_LOG.md。

ChronoArch-F 保留三个方法改进点：DINOv2 ViT-L/14 的 224/448 多尺度局部 token由可学习查询交叉注意力聚合；DINOv2、CLIP ViT-L/14、SigLIP 2 ViT-B/16由逐维门控融合；风格、细风格、年份三任务头联合训练。所有深度模型训练和前向均显式使用 CUDA，训练采用 fp16 自动混合精度。

## 相对原 v2 计划的全部压缩改动

1. 两个尺度的 DINOv2-L patch token 分别做 2×2 平均池化，成为各 8×8、64 个 token；连同 CLS、CLIP-L、SigLIP 2 和 base/flip 视图按任务载入内存。不使用随机裁剪视图；B-7 的 token 在其阶段载入，以控制内存。

2. 运行 ChronoArch-F 与 B-1 至 B-7；不运行 ChronoArch-L、B-8、B-9。微调比较仅引用原论文已发表的 WC6 参考值：ResNet-50 60.2%、TResNet-M 69.5%，来源为 [Barz 与 Denzler，WikiChurches，NeurIPS 2021](https://datasets-benchmarks-proceedings.neurips.cc/paper_files/paper/2021/file/eccbc87e4b5ce2fe28308fd9f2a7baf3-Paper-round2.pdf)；它们不是本轮运行结果，也不纳入配对检验。

3. ChronoArch-F 的超参数搜索只用 seed 0：先固定 λ_fine=1、λ_year=0.3、τ=1，搜索 K∈{4,8} × lr∈{5e-4,1e-3} 四组；再固定最佳 K/lr，搜索 λ_fine∈{0.3,1} × λ_year∈{0.3,1} × τ∈{0,1} 八组。重复的配置复用已完成训练。WC6、WC14、WC4 各用本任务验证集；RQ3a Gothic/Romanesque 及 RQ3b 仅在第 1 折内部验证集选模，配置用于全部五折。最多 40 epoch，早停 patience=6。全部验证记录见 selection_log.csv。

4. ChronoArch-F 与可训练基线 B-3、B-5、B-7 的最终结果使用 seeds 0–2，报告单 seed 均值±SD、三 seed 集成及翻转测试增强。B-2、B-4、B-6也保存三 seed 预测；其确定性线性模型的 SD 可为零。B-1 是第一轮单 seed 的 image_only 预测复用，无法提供三 seed SD 或集成。

5. WC6 与 Gothic 的消融保留 A0–A4、R2、R4；R1（ViT-B 骨干）只在 WC6。A0–A4、R1、R2 以三 seed 汇总；R4 正式报告只用 seed 0，不做 seed 集成和翻转增强，并与 A0 seed 0 配对。此前依旧方案产生的 R4 seed 1/2 预测保留但不纳入正式汇总。

6. 旧方案训练记录及检查点以 .superseded 保留；中断或不完整文件以 .incomplete 保留，未删除其他文件。压缩方案前三次 WC6-F 训练实测 31.828、28.031、31.219 秒，来源为 selection_log.csv。

## 测试输入与标签使用

ChronoArch-F 的测试前向只调用 FeatureStore.batch 取得图像的 DINOv2、CLIP、SigLIP 2 特征；线性与神经基线的预测函数也只读取图像特征。风格标签和年份用于训练损失、验证选模及预测后评估，不作为测试图像的模型输入。B-1 断代复用记录筛选 method=image_only。RQ4 先对图像特征做 GPU 推理，再读专家标注计算正确率。

## 公平基线重跑

仅重跑 B-2 至 B-7；ChronoArch-F 的配置、训练、检查点和测试预测均沿用原结果。旧基线文件保留。本节所有新文件位于 `results_v2/baselines_fair/`。

B-2、B-4、B-6 对各编码器特征分别做 L2 归一化后拼接；分类 C 与断代 Ridge alpha 的初始网格均为 {1e-4, 3e-4, 1e-3, 3e-3, 1e-2, 3e-2, 0.1, 0.3, 1, 3, 10}，若验证最优落在边缘则按十倍向外扩展。B-3、B-5、B-7 在 seed 0 上搜索 lr × τ × dropout 共 8 组，训练使用 base/flip 增强、fp16 CUDA、40 epoch 上限与 patience 6；选中配置使用 seeds 0–2 并做翻转测试增强和三 seed 集成。断代任务不使用风格 logit adjustment，τ 对断代损失无作用；该网格仍按要求记录。

所有配置只用验证集选出。Gothic、Romanesque、断代只在第 1 折内部验证集选超参数和比较基线，后四折沿用；最终测试预测每个配置仅评估一次。B-2/B-4/B-6 为确定性模型，表中只有一个独立 seed；其额外 seed 不会提供新的随机重复。95% CI 使用 1,000 次教堂级 bootstrap。正差值表示 ChronoArch-F 更好，断代表示 MAE 降低年数。Holm 校正涵盖本节十项预定配对检验。
